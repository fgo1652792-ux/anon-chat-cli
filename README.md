# anon-chat-cli

واجهة سطر أوامر تفاعلية للدردشة المجهولة، تحفظ **الجلسات** و**المحادثات** محليًا حتى
تكمل من نفس الهوية ونفس السياق بكل تشغيل، بدل ما تبدأ من الصفر.

> ⚠️ تنبيه: هذا عميل غير رسمي يستخدم endpoint تطبيق أندرويد (Anonymous/guest).
> قد يتغيّر شكله أو يحدّ من الطلبات بأي وقت، واستخدامه خارج تطبيق OpenAI الرسمي
> قد يخالف شروط الخدمة. استخدمه على مسؤوليتك.

## التشغيل

```bash
python3 chat_cli.py
python3 chat_cli.py --store ./my_store.json   # مسار مخزن مخصص
```

يتطلب Python 3.8+ فقط، بدون أي مكتبات خارجية.

## الأوامر داخل البرنامج

```
/help                  هذه القائمة
/exit                  خروج

الجلسات (الهوية):
  /sessions            عرض الجلسات والمحادثات
  /newsession [اسم]    جلسة هوية جديدة تمامًا
  /session <id>        التبديل إلى جلسة محفوظة

المحادثات (السياق):
  /new [عنوان]         محادثة جديدة داخل الجلسة الحالية
  /open <id>           فتح محادثة محفوظة
  /title <نص>          تغيير عنوان المحادثة الحالية
  /history             عرض رسائل المحادثة الحالية
  /clear               مسح رسائل المحادثة محليًا
```

## شنو يُحفظ وشنو لا

| يُحفظ في المخزن | ما يُحفظ |
| --- | --- |
| `device_id` | ✔ |
| `client_session` | ✔ |
| cookies | ✔ |
| `conversation_id` + `parent_id` | ✔ |
| سجل الرسائل محليًا | ✔ |
| التوكن | ✘ — يُطلب من جديد بكل تشغيل |

المخزن الافتراضي: `~/.chat_cli_store.json` بصلاحيات `600`.

## ملاحظات تقنية

- `conversation_id` يجي بمستوى الحدث في الـSSE، مو داخل `v`، ولهذا يُقرأ من
  `ev.get('conversation_id')` مع دعم الشكل القديم أيضًا.
- ردود الـassistant تجي كمقاطع متزايدة (incremental snapshots)، ويُؤخذ أطول نص
  لكل `message_id` لتفادي التكرار.
